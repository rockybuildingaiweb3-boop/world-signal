# Editorial Content

Muse writes one daily canonical Markdown edition to:

`content/editions/YYYY/MM/YYYY-MM-DD.md`

This is the source of truth. The copies under `public/editions/` are generated by the publishing workflow and must not be edited manually.

Start from `content/templates/daily-edition.template.md` and follow `docs/CONTENT_SCHEMA.md`.

Morning, midday, and evening runs replace the same date's complete cumulative file. Do not create separate files for each run or append duplicate stories. Keep historical editions and reuse stable IDs for ongoing stories.
